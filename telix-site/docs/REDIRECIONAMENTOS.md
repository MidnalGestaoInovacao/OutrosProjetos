# Redirecionamentos 301 sugeridos (site antigo → novo)

Aplicar no servidor do domínio definitivo (ou com o plugin *Redirection*) no momento da migração, para preservar
links antigos e o histórico de busca.

| URL antiga (www.telixcom.com.br) | Nova URL |
|---|---|
| `/` , `/index.php`, `/index.html` | `/` |
| `/#empresa` | `/a-telix/` |
| `/#servicos-ctrl` | `/solucoes/` |
| `/#trabalhe`, `/trabalhe.php` | `/trabalhe-conosco/` |
| `/#denuncia` | `/canal-de-denuncia/` |
| `/#contato`, `/contact_process.php` | `/contato/` |
| `/servicos.html` | `/clientes/` |
| `/lgpd/`, `/lgpd/index.html` | `/conformidade/` |
| `/lgpd/politicas.html` | `/conformidade/politica-de-privacidade/` |
| `/lgpd/glossario.html` | `/conformidade/glossario-lgpd/` |
| `/lgpd/cookies.html` | `/conformidade/politica-de-cookies/` |
| `/lgpd/index.html#comites` | `/conformidade/` |
| `/lgpd/index.html#contato` | `/canal-lgpd/` |
| `https://telixcom.com.br/*` (sem www) | `https://www.telixcom.com.br/*` (ou o domínio canônico escolhido) |

Âncoras (`#…`) não chegam ao servidor; para elas, o próprio site novo já possui as páginas correspondentes.
